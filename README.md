# 墨砚 Inkstone

一个装在浏览器里的私人阅读器。**书在你自己手上，不在任何人的服务器上。**

导入 PDF / EPUB / TXT / MD，划线、写想法、检索、朗读，最后把批注导进 Obsidian 变成双向链接的笔记。所有数据存在浏览器本地（IndexedDB），不上传、不联网、不需要注册账号。

整个应用是**一个文件**：`inkstone/index.html`。双击就能用。

---

## 现在能做什么

### 书架
- 导入 PDF / EPUB / TXT / MD，点击或拖放都行，自动生成封面
- 排序：最近阅读 / 最近添加 / 按书名 / 按进度
- 筛选：PDF / EPUB / 文字 / 在读 / 有批注
- 本周阅读时长统计

### 阅读
- 四种主题：纸白 / 墨黑 / 暮灰 / 夜黄
- 字号 12 档、行距 5 档、段距 3 档、字体三种（宋体 / 黑体 / 等宽）
- 工具栏 5 秒自动隐藏，读的时候不挡视线
- **朗读**：可换声音、调语速（0.6–1.5×）、**逐句朗读**（句间有自然停顿，停止也更跟手）

#### 关于朗读的声音

朗读用的是**你电脑自带的语音库**，不联网、不上传任何文本，所以音质完全取决于本机装了什么。

音色分四档，从机械到自然依次是：**紧凑 < 标准 < 增强 < 高级**。设置面板的语音下拉里会给每一项标注档位，并自动把最好的排在最前。

觉得机械的话，去装一档更好的：

- **macOS**：系统设置 → 辅助功能 → 朗读内容 → 系统语音 → 管理语音 → 中文（普通话）→ 下载「增强」或「高级」版本。装完回到墨砚的设置里选它，自然度会明显提升。
- **Windows**：设置 → 时间和语言 → 语音 → 添加语音 → 选中文的「自然」语音。

> 注：部分系统的顶级神经语音（如 Siri 系列）不对第三方浏览器开放，Web Speech API 拿不到，这是浏览器限制而非本项目的问题。

### 批注
- 四色高亮（朱砂 / 黛蓝 / 藤黄 / 苔绿）+ 下划线 + 文字想法
- **PDF 支持真实划词**：划哪句就高亮哪句，翻页和重开都能精确还原
- **划词即写**：划完后在工具条里直接写想法，**不弹窗、不遮挡原文**。
  写完点色块或按回车即存，选区在输入框聚焦的瞬间就存好了快照，不会丢
- PDF 书签目录自动生成章节，没有书签的书回退成「每页一章」
- 鼠标悬浮高亮可回看当时写的想法
- 朗读（PDF 读当前页，EPUB/TXT 读当前章）

### 检索
- 全文 + 批注一起搜，输入即搜（300ms 防抖）
- 跨书检索，点结果自动打开那本书并跳到原文位置

### 批注总览
- 所有书的批注按书分组，可按书 / 按颜色 / 按「写没写想法」筛选，可切换 最近添加 / 按书内位置 排序
- **密度自检**：告诉你平均每个章节（或每页）留了几条带想法的批注，并判定 未落笔 / 偏稀 / 适中 / 偏密
- **就地补想法**：未写想法的条目显示「＋ 写想法」，点开就地输入，回车即存
- 按书折叠 + 分批加载（每批 80 条，滚到底自动加载），几百条也不卡
- 勾选任意条数，导出为 Markdown

### 导出
- **Markdown** 单文件
- **Obsidian 笔记包**：主笔记 + 分章笔记 + 每条批注独立块 ID，`![[章节#^ink-xxx]]` 双向链接，可直接拖进 vault
- **备份 / 恢复**：完整 JSON，跨设备迁移或换浏览器时救数据

### AI（可选）
- 本地抽取式摘要 + 基于 IDF 的问答，**不联网也能用**
- 想用更好的效果，设置里填一个 OpenAI 兼容接口的 Base URL + Key 即可（只存在本机）

```
git clone https://github.com/art13817979231-svg/inkstone.git
cd inkstone
open inkstone/index.html
```

## 技术说明

| | |
|---|---|
| 形态 | 单文件 HTML，无构建、无打包、无后端 |
| 存储 | IndexedDB（书 + 批注 + 进度），偏好存 localStorage |
| PDF | pdf.js 3.11.174，自建 textLayer 实现划词高亮 |
| EPUB | JSZip 解包 + 自写 OPF/NCX 解析（支持 `dc:` 命名空间） |
| ZIP 打包 | 内置 store 模式 ZIP writer，零依赖，离线可用 |
| 视觉 | Swiss 极简：纸白 `#fafaf7`、墨黑 `#1a1a1a`、朱砂 `#c8102e`，Songti SC + Courier New |

**PDF 中文检索**：很多 PDF 用的是康熙部首（U+2F00–U+2FDF）而不是正字，直接搜会搜不到。项目内置 298 条查表映射，检索时对查询词和正文**双边归一化**。注意不能用 NFKC —— 它会把全角标点一起毁掉。

**数据不会被清空**：删书、清空书架前都会强制提醒先备份。恢复备份按 ID 去重，可重复执行，不会覆盖已有阅读进度。

## 已知限制

- 旧版本导入的 PDF，正文里的部首字要**重新导入**才能被检索到（textLayer 是导入时生成的）
- PDF 里跨文本块的一句长话，重绘时会拆成多个 `<mark>`（pdf.js 按字符坐标切分 span 所致，视觉上仍是连续的一条）
- 内联想法输入框上限 600 字；更长的想法请用侧栏「编辑」走全屏弹窗
- 朗读不支持"跟读高亮"（正在读哪句没有视觉提示），且音质受限于本机语音库
